## Website

本站采用 **React 19 + Vite 6** 构建，以深色空间叙事、克制的图形语言与研究型项目展示为设计主线。

- **交互展示**：全屏动态首页、项目卡片与独立项目详情视图。
- **内容组织**：个人背景、实习与项目实践、研究论文、专业技能及联系方式。
- **视觉表达**：地形、地图网格与空间数据元素相结合的响应式布局。
- **工程部署**：GitHub Actions 自动构建，GitHub Pages 托管。

### 技术栈

`React` · `Vite` · `JavaScript` · `CSS` · `Lucide Icons` · `GitHub Pages`

### 本地开发

需要 Node.js 环境。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```
